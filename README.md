# PE 262: Radial Flow Dashboard

This application is a cloud-deployed engineering dashboard designed to instantly visualize the steady-state radial flow of an undersaturated volatile oil using Darcy's Law. It was developed to analyze dynamic reservoir parameters including permeability, pressure differential, and fluid viscosity.
